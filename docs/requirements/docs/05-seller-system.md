# Seller System

## Seller Onboarding
Seller registration must collect required business and KYC information.

Workflow:
1. Seller registers.
2. Seller submits required documents/details.
3. Admin reviews documents.
4. Admin approves or rejects seller.
5. Only approved sellers become fully active.

## Seller Statuses
Suggested statuses:
- Draft
- Submitted
- Under Review
- Verification Required
- Approved
- Rejected
- Suspended
- Deactivated

## Seller Listing Submission
Seller has two submission options:
1. Upload product photos/catalogue/material.
2. Fill product information manually using available product fields.

Both paths create a listing submission for Admin review.

## Seller Permissions
Seller cannot directly publish a new marketplace product.

Seller can review admin-created/edited listing information and:
- Confirm
- Request changes
- Reject/request corrections

## Seller Data
Maintain seller:
- Business profile
- Contact details
- KYC status
- Documents
- Approval status
- Products/listings
- Orders
- Settlement/commission data
- Revision history

## Confirmed Decisions Update

Seller-managed inventory is authoritative for seller-owned listings; support quantity, status, adjustments, low-stock threshold and history. Both Seller and Admin can contribute/manage listing images, with changes traceable through the listing workflow.
