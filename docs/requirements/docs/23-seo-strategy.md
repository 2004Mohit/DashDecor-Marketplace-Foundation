# SEO Strategy

## Goal
Strong technical, product and category SEO for the Pune/Pimpri-Chinchwad launch, with a foundation for future multi-city expansion.

## Technical SEO
Implement:
- Clean URLs
- SEO-friendly rendering
- Unique page titles
- Meta descriptions
- Canonical URLs
- XML sitemap
- Robots.txt
- Breadcrumbs
- Structured data
- Open Graph metadata
- Proper headings
- Image alt text
- Indexation controls

## Structured Data
Where applicable:
- Product
- BreadcrumbList
- FAQ
- Organization
- Website/SearchAction where appropriate

## Product SEO
Each indexable product page should support:
- Product name in H1
- Descriptive content
- Specifications
- FAQs
- Brand
- Pricing/availability data where valid
- Product structured data

## Category SEO
Category pages should support:
- Unique title/meta
- Introductory useful content
- Internal links
- Product listings
- Breadcrumbs

## Local SEO
Initial location focus:
- Pune
- Pimpri-Chinchwad

Future:
- City/location landing pages should be generated only where meaningful and supported by real inventory/service information.

## Content
Client provides final content. Placeholder/demo content must be replaceable.

## Important
Do not create thousands of thin programmatic SEO pages simply to target keywords.
