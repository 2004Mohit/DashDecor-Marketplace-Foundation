# Future Roadmap

## Planned
1. Android application
2. iOS application
3. Multiple cities
4. Multiple warehouses

## Architecture Principle
V1 should avoid assumptions that make these future capabilities require a complete rewrite.

## Future Marketplace Capabilities
Potential future extensions:
- Advanced seller plans
- B2B pricing tiers
- Saved project material lists
- Repeat orders
- Credit terms
- Advanced seller settlement
- More delivery partners
- Multi-location inventory
- City-specific catalogues and delivery rules

## Future Customer Capabilities
Potential:
- Personalized recommendations
- Advanced loyalty
- Saved projects
- Reordering
- Additional communication channels

## Rule
Future features should not be implemented merely because they are on the roadmap. V1 should remain focused and maintainable.

## Confirmed Decisions Update

Architecture must support future pan-India expansion, multiple cities and multiple warehouses. Seller inventory should remain separate from canonical product data and be extensible to multiple inventory locations.
