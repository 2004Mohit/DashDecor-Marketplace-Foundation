# Product Catalogue System

## Catalogue Hierarchy
Support:
- Categories
- Subcategories
- Brands
- Products
- Variants
- Attributes
- Seller associations

## Product Lifecycle
Suggested statuses:
- Draft
- Seller Submitted
- Admin Review
- Admin Editing
- Seller Review
- Change Requested
- Approved
- Published
- Rejected
- Archived

## Product Content
Support structured and rich content:
- Product name
- Short description
- Full description
- Highlights
- Specifications
- Usage/application
- FAQs
- Images
- Variant information
- Brand
- Category
- GST/tax data
- Price
- Inventory

## Inventory
Inventory must be seller-aware and future-ready for multiple warehouses.

The system should not assume one global stock location.

## Search
Catalogue data must be structured to support:
- Product search
- Category browsing
- Brand filtering
- Price filtering
- Attribute filtering
- Availability
- Pincode-related availability
- Sorting

## Confirmed Decisions Update

Categories/subcategories are Admin-managed and database-driven. Seller inventory is separate from canonical product data. Products can have seller-specific listings and stock. Product/category tax classifications connect to the configurable tax engine. Images may originate from Seller or Admin.
