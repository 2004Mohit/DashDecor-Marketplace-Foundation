# Delivery System

## Initial Geography
Pune and Pimpri-Chinchwad.

## Eligibility
Same-day delivery only when eligible.

Eligibility can depend on:
- Seller
- Product
- Inventory
- Pincode
- Distance
- Product dimensions
- Weight
- Product type
- Delivery class
- Delivery capacity
- Delivery schedule

## Configurability
Delivery rules must be Admin-configurable.

Avoid hard-coded delivery thresholds.

## Delivery Calculation Inputs
Potential inputs:
- Origin/seller location
- Destination pincode/address
- Distance
- Weight
- Dimensions
- Product delivery class
- Seller delivery capability
- Same-day eligibility
- Order value
- Configured delivery rate

## Ground-Level Limitation
Delivery:
- Includes unloading.
- Includes keeping the product at the designated ground-level place.
- Does not include shifting products to upper floors.

This must be shown before order placement.

## Pickup
Support seller/showroom pickup where configured.

## Future
Design for:
- Multiple cities
- Multiple warehouses
- Multiple inventory locations
- Delivery partners

## Confirmed Decisions Update

Seller may configure delivery availability where Admin permits; Admin retains platform authority. Serviceability considers seller inventory, seller location, product characteristics, pincode and configured delivery rules.
