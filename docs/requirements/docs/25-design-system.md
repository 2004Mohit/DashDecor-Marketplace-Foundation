# Design System

## Brand Direction
Brand reference: DashDecor.

## Style
Premium luxury.

Reference websites:
- Fixxly
- HomeRun
- Material Depot
- Plywala
- Ebco

These are references for UX/design patterns only, not templates to copy.

## Themes
Support:
- Light Mode
- Dark Mode

Both must be intentionally designed.

Do not simply invert colors.

## Visual Goals
- Premium
- Modern
- Clean
- Architectural/interior-focused
- High-quality product imagery
- Strong typography
- Generous spacing
- Clear hierarchy
- High trust

## Logo
Create a simple initial premium logo concept. It must be replaceable without restructuring the application.

## Loading Experience
Use an application-level premium loading experience:
- Not a separate route
- Smooth transition into homepage
- No unnecessary delay
- Non-critical assets must not block application usability

## Responsive
Design for:
- Mobile
- Tablet
- Laptop
- Desktop

Mobile-first commerce interactions are important.

## Accessibility
Use:
- Semantic HTML
- Keyboard navigation
- Visible focus states
- Accessible labels
- Adequate contrast
- Reduced-motion considerations where applicable

## Confirmed Decisions Update

DashDecor is a temporary working name; logo/name/brand assets must be replaceable without restructuring. Premium luxury design with intentionally designed Light and Dark modes.
