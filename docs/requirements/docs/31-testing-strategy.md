# Testing Strategy

## Functional Testing
Test:
- Registration/login
- Phone OTP
- Guest checkout
- Product browsing
- Search
- Filters
- Cart
- Wishlist
- Checkout
- Cashfree payment
- Pay on Delivery
- Orders
- Refunds
- Reviews
- Notifications
- Seller onboarding
- KYC verification
- Seller product submission
- Admin listing review
- Seller listing confirmation
- Revision/change requests
- B2B enquiries
- Quotes
- Delivery eligibility

## Security Testing
Test:
- RLS
- Role boundaries
- Unauthorized access
- Private storage
- Payment verification
- Webhook authenticity/idempotency
- Input validation
- File upload restrictions

## UI Testing
Test:
- Mobile
- Tablet
- Desktop
- Light mode
- Dark mode
- Loading states
- Empty states
- Error states
- Accessibility basics

## Performance
Test:
- Core Web Vitals
- Image loading
- JavaScript bundle size
- Product/category page performance
- Mobile performance

## SEO
Verify:
- Titles
- Meta descriptions
- Canonicals
- Sitemap
- Robots
- Structured data
- Indexability
- Open Graph
- Breadcrumbs

## Financial Testing
Test:
- Product totals
- Taxes
- Fees
- Commission
- Delivery charges
- Discounts if introduced later
- Refund calculations
- Seller settlement calculations

## Acceptance
No production launch until critical payment, authorization, RLS and order lifecycle tests pass.
