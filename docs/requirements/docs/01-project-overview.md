# Project Overview

## Project
Pune Interior & Construction Materials Commerce Platform.

## Business Model
Hybrid marketplace:
- Platform-owned/direct products may be supported.
- Third-party local sellers can list and sell products.
- B2C and B2B customers are supported.

## Initial Geography
- Pune
- Pimpri-Chinchwad

Future:
- Multiple cities
- Pan-India expansion
- Multiple warehouses

## V1 Scope
The platform includes product commerce, seller onboarding and listing workflows, B2C/B2B ordering, quotations, delivery, payments, reviews, notifications, admin management and strong SEO.

Interior design/service booking is explicitly out of V1.

## Technology
- Frontend: React + Vite
- Hosting/CDN/DNS: Cloudflare Pages + Cloudflare
- Backend: Supabase
- Database: PostgreSQL
- Authentication: Supabase Auth
- Storage: Supabase Storage
- Server-side logic: Supabase Edge Functions
- Realtime: Supabase Realtime where required

## Development Approach
Replit is the primary AI development assistant. Development must be phased and manually reviewed for security, payments, financial calculations, permissions, SEO, performance and production configuration.

## Confirmed Decisions Update

DashDecor is a temporary working name. Categories are Admin-managed; sellers manage their own inventory; both sellers and admins can manage product images through the approval workflow; B2B requires business-profile verification; tax is system-calculated from Admin-configurable rules; Replit starts from an empty project.
