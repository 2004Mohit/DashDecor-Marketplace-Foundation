# Admin Panel

## Dashboard
Provide operational summaries for:
- Orders
- Revenue/payment status
- Seller verification
- Listing submissions
- Pending approvals
- Inventory alerts
- Quotes/enquiries
- Reviews
- Delivery activity

## Modules
- Dashboard
- Products
- Categories
- Brands
- Variants
- Inventory
- Orders
- Customers
- Sellers
- Payments
- Refunds
- Reviews
- Enquiries
- Quotes
- Delivery
- Blogs
- SEO Settings

V1 excludes:
- Banners
- Coupons

## Seller Verification
Admin can:
- View seller details
- View required documents
- Approve
- Reject
- Request additional information
- Suspend/deactivate

## Listing Workflow
Admin can:
- Review seller submissions
- Create/complete listing
- Edit product data
- Modify category/brand/variant information
- Modify images/content
- Send to seller
- Accept seller confirmation
- Request corrections
- Reject

## Configuration
Admin can configure:
- Commission rules
- Platform fees
- Seller/category-specific fee rules
- Delivery rules
- Product/category attributes
- Availability rules
- Other business settings

## Auditability
Important administrative actions should create audit records.

## Confirmed Decisions Update

Admin controls categories/subcategories, category attributes, tax classifications/rules, B2B verification, seller KYC, listing revisions, inventory oversight, commission/platform fees and delivery rules. Seller remains responsible for seller-owned inventory updates.
