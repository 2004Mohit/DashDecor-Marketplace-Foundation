The current project foundation is already implemented.

I want to revise the visual color direction before continuing with backend/database development.

## Reference

Use the visual energy and bright commerce feel of:

https://www.fixxly.in/

**DO NOT COPY FIXXLY.**

Do not reproduce its:

* Color palette
* Branding
* Logo
* Layout
* UI components
* Exact visual style

* Dark

* Corporate

# IMPORTANT

Do not blindly apply these colors everywhere.

Create a proper design-token system so the palette can be changed later from a central location.

For example:

```text
--color-primary
--color-primary-hover
--color-accent
--color-background
--color-surface
--color-text
--color-text-muted
--color-border
```

If the current project uses another token architecture, adapt it rather than creating duplicate systems.

---

# LIGHT MODE

Light Mode should be the primary/default experience.

Visual direction:

```text
Warm Ivory background
+
White surfaces
+
Cobalt interactive elements
+
Small Lime highlights
+
Dark charcoal typography
```

The result should feel bright and premium.

Avoid excessive shadows.

Prefer:

* Clean borders
* Soft elevation
* Large whitespace
* Strong typography
* High-quality imagery
* Subtle depth

---

# DARK MODE

Keep Dark Mode supported.

Do NOT simply invert the light theme.

Create a separately designed dark theme using the same brand identity.

Suggested direction:

```text
Deep charcoal background
+
Dark elevated surfaces
+
Cobalt primary
+
Controlled lime accents
+
Warm/light typography
```

The dark theme should still feel premium and polished.

# TYPOGRAPHY

Keep typography modern and highly readable.

Prioritize:

* Strong headings
* Clean body text
* Clear price hierarchy
* Good spacing
* Excellent mobile readability

Avoid decorative fonts that reduce usability.

---

# COLOR ACCESSIBILITY

Verify sufficient contrast.

Do not use lime text on white.

Do not use low-contrast gray text for important information.

Interactive elements must remain clearly identifiable.
